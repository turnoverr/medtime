v1.9.2 Latest
What's new
  • Heatmap and adherence streak now appear in Advanced Mode — the 28-day calendar and streak banner are shown below the slot history, not just in Simple Mode (R-25)
  • Changelog kept current and accurate across all versions — non-negotiable going forward
v1.9.1 New
What's new
  • 5-step onboarding — slot-based setup routes users to the right mode from first launch (R-23)
  • Schedule type question — "Doctor's schedule" routes to Advanced Mode; "Daily reminder" routes to Simple Mode (R-17)
  • Slot selection — tap Morning, Lunch, Dinner, Bedtime; configure each with a time and medications before the app loads (R-23)
  • Patient name personalisation — when setting up for someone else, their name appears in the mode badge and throughout the app (R-20)
  • Context-aware onboarding questions — "you/your" or the patient's name depending on who the app is for (R-24)
  • Done screen — warm confirmation showing the full configured schedule before entering the app
  • Progress indicator — pill-shaped segment bar tracks position across all steps
v1.9 New
What's new
  • D1 Capsule Grid logo — new SVG brand mark replaces pill wordmark across all surfaces
  • Fraunces typeface — distinctive serif/italic pairing for Med/Time wordmark
  • Teal primary palette (#2DCFC9) replaces previous green/blue accents throughout
  • Redesigned onboarding — logo-led flow, pill-bar progress indicators, teal CTA buttons
  • All interactive accents updated — buttons, focus states, slot cards, badges all teal-consistent

v1.8 New
What's new
  • Caregiver Access — PIN-protected codes with slot-level permissions; shared via URL; PIN never in URL or source (R-15)
  • Caregiver Management panel — codes, permissions, last-used time; block or delete instantly
  • Caregiver mode — full teal visual shift; all action buttons hidden; "Caregiver View" badge
  • 3-step onboarding — name, reminder time, first medication on first launch
  • 28-day heatmap — green (taken), amber (early), red (missed), today ringed in teal
  • Streak & adherence banner — 🔥 streak count and 28-day percentage
  • Advanced Mode — 4 dose slots (Morning, Lunch, Dinner, Bedtime), smart hierarchy by device time
  • Haptics on every interaction — light, medium, success, error patterns
