What's New
v1.9 New Latest
What's new
  • D1 Capsule Grid logo — new SVG brand mark replaces pill wordmark across all surfaces
  • Fraunces typeface — distinctive serif/italic pairing for Med/Time wordmark
  • New colour system — teal primary palette (#2DCFC9) replaces previous green/blue accents
  • Redesigned onboarding — logo-led flow, pill-dot progress indicators, teal CTA buttons
  • All interactive accents updated — buttons, focus states, slot cards, badges all teal-consistent
v1.8 New Latest
What's new
  • Caregiver Access — create PIN-protected codes with slot-level permissions. Share a single URL; PIN is entered on arrival and never appears in the URL or source code
  • Caregiver Management panel — see all codes, permissions, last-used time; block or delete any code instantly
  • Caregiver mode now shows a full teal visual shift — pill logo, orb, ring, and a "Caregiver View" badge all teal; all action buttons hidden
  • Onboarding flow — 3-step setup on first launch (name, reminder time, first medication)
  • Streak & adherence banner above history — 🔥 streak count and 28-day percentage
  • 28-day heatmap calendar — green (taken), amber (early), red (missed), today highlighted with blue ring
  • Advanced Mode — 4 dose slots (Morning, Lunch, Dinner, Bedtime), full-width stacked cards, smart hierarchy based on device time
  • Haptics on every interactive element — light tap on navigation, medium on confirms, success pattern on dose taken, error pattern on wrong PIN
  • Configurable early-take window in Settings (15 min / 30 min / 1 hr / 2 hrs / 3 hrs / always ask)
  • Structured medication fields — form, route, food timing, instructions
  • Push-down banner — slides page content down so header is always visible; swipe up to dismiss, no close button
  • Mode badge centred below pill logo — Simple / Advanced / Caregiver View
Fixed
  • Complete clean rebuild from v1.5.3 — all v1.7.x JavaScript errors resolved
  • fmtMins function declaration was missing, causing fatal syntax error that broke entire app
  • Swipe banner touch listeners moved inside init() — no longer run before DOM is ready
  • Haptic wrappers removed — haptics now called directly inside each action function
  • All input fields constrained to screen width — no overflow on mobile
  • Logo always centred — unaffected by mode or caregiver state
